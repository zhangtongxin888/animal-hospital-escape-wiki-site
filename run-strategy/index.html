How to use the three-phase model

For planning only, this guide groups the counter into 0–3, 4–7, and 8–10. These are not official difficulty thresholds. The confirmed rule is that every Medkit makes the Anomaly faster and smarter and causes it to adapt to behavior.

Recommendation

0–3: orient and establish a route

  • Identify landmarks visible in the current run.
  • Record each pickup immediately on the tracker.
  • Notice which areas you have actually searched instead of trusting vague memory.
  • Do not assume the early threat pace will remain stable.
Recommendation

4–7: reduce repeated decisions

Use landmarks to make route choices quickly. If you catch yourself repeating the same uncertain path, stop at a recognizable point and choose an area that is more likely to be unsearched.

  • Keep the next destination simple and recognizable.
  • Reassess after every pickup rather than following the opening route on autopilot.
  • Treat sound as relevant without assuming undocumented detection values.
Recommendation

8–10: close the objective deliberately

Late in the run, the confirmed escalation has occurred many times. Prioritize areas you can navigate with confidence and avoid adding optional exploration to the final search.

At 10/10, follow the live escape prompt. This guide does not claim a fixed exit location or a guaranteed final route.

Recommendation

Recover when a route breaks down

  • Return to a recognizable landmark if doing so is safely possible in the current situation.
  • Rebuild the list of searched areas from memory instead of improvising a full map.
  • Change one repeated behavior before attempting the same path again.
  • Use the current game interface for controls, prompts, and the final escape instruction.
